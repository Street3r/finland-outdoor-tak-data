KML network links

ATAK: Import → KML Link → paste one of the URLs below and turn on auto refresh (e.g. 86400 s). The areas appear as child links in Overlay Manager → Network Resources, where they can be switched on and off. A single area works the same way with its kmz URL from the table below. WinTAK / Google Earth: open the .kml file.
