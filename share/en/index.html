Finland outdoor TAK data

Scan a QR code with the phone camera and open it with ATAK, or tap a button on the phone. ATAK asks before importing. iTAK and WinTAK: use the download links.

1. Icon set (install once)

Without it the markers show default icons.

2. All areas as auto-refreshing layers

Scan the QR code or tap the button on the phone: ATAK adds an auto-refreshing link (Overlay Manager → Network Resources), refreshed daily. National parks, wilderness areas and state hiking areas are on by default and regions off (they contain the same sites too); switch regions on one by one. Other apps: download the .kml file or copy its URL.

KML layers are an overview: routes are plain lines and hashtag search does not cover them.
